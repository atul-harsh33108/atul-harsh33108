## 📄 Publications

> Peer-reviewed IEEE conference papers — because research and production should feed each other.

<table>

<td width="50%">

### 📑 [MORAG: A Multimodal Offline RAG System Using LLMs](https://ieeexplore.ieee.org/document/11613599)

**2026 18th International Conference on Electronics, Computers and Artificial Intelligence (ECAI)** · IEEE
📍 Bucharest, Romania · July 2026

A fully **offline multimodal RAG** system — text, image & audio — with zero cloud APIs:

- 🔌 **Local-first architecture:** encoding → retrieval → generation entirely on local hardware, for privacy-sensitive & resource-constrained environments
- 🧩 **Multimodal pipeline:** MiniLM (text) · Whisper (audio) · CLIP + Tesseract OCR (images), unified indexing in a local ChromaDB vector store with hybrid retrieval
- ⚡ **Efficient local inference:** Phi-3 Mini (3.8B) with 4-bit GGUF quantization + hybrid CPU-GPU offloading via Ollama
- 📊 **Results:** **0.86 Recall@5** overall (0.91 text · 0.82 audio · 0.76 image) · **42.1 tokens/s** · **120 ms time-to-first-token** on RTX 3050 4GB, peak VRAM 3.8 GB
- 🌍 **Impact:** privacy-preserving, explainable, low-latency multimodal assistants for offline / disconnected / low-bandwidth environments

**2026 World Conference on Computational Science and Technology (WcCST)** · IEEE
